## Overview

E-commerce web project with static pages and a Node.js backend for authentication, password reset flow, and API routes.

## Tech Stack

- Node.js
- Express
- MongoDB (Mongoose)
- HTML/CSS/JavaScript

## Setup

```bash
npm install
```

## Environment Variables

Create a `.env` file based on `.env.example`.

## Run

```bash
npm start
```

Default backend port is `3001` unless `PORT` is set.

## Main Files

- `server.js`
- `index.html`
- `shop.html`
